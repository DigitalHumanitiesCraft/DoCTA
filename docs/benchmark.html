    The iterations compared

    What the measures mean
    Reading the figures
    CER is an error rate against the human reference, so lower is better; consistency is the agreement between the repeated runs of one page on a scale from 0 to 1, so higher is better. A figure is marked as the better one only where it leads the other iteration by more than one CER point, or by more than 0.05 in consistency. Smaller differences lie inside the scatter of the repeated runs and stay unmarked.
    Prompt iteration
    A system prompt frozen after its first run. it01 is the baseline prompt of 2026-08-26; it02 splits a shared core prompt from one genre module per text type, inventory or account book, synthesized from three analysis reports of the same day. A prompt is never edited; a change becomes a new iteration, so the results of every earlier one stay comparable.
    Repeated runs (k)
    The same request to the same model at temperature 0 does not return the same text. In the first iteration identical requests scattered by up to 5.5 CER points, so a ranking built on single runs is noise. Every page is therefore transcribed several times per iteration, most often on the pages carrying a human reference.
    CER fair
    Character error rate against the human reference transcription from the Inventaria edition, measured after the normalization profile documented in the runner, which forgives allograph and spacing conventions of the writing hand. 0% would be an exact match after normalization.
    CER strict
    The same comparison against that Inventaria reference on exact characters, with no normalization. It sits above CER fair and shows how much of the agreement rests on the normalization rather than on the reading.
    Word and number consistency
    Position-wise agreement of tokens between the repeated runs of one page, once over word tokens and once over number and currency tokens. This is self-consistency, not correctness: all runs can agree on the same wrong reading. The number measure carries weight on the account-book pages, where the amounts are the point.
    Lines
    The line counts of the individual runs. A spread between them signals that the model segments the page differently from run to run.
